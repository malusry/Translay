# Translay 接续回环

## 符号含义

- **延展 t**：t 的纵向笔画向下拉伸并连续回转成环；横画只留下轻微提示，不主导轮廓。
- **回环**：纵向轨迹完成一次理解并绕回外侧，表示翻译发生后用户仍留在原来的工作流。
- **圆形负空间**：环内保留一个清晰的圆形场，表示被选中的文字与一次完整理解。

## 设计边界

- 保持单色、同一笔性、圆形核心负空间。
- t 必须由纵向主轨迹自然产生，禁止再放入独立字母或强化横向十字结构。
- 不加入箭头、语言字符、节点、渐变、阴影或应用界面外框。

## 文件

- `translay-loop-mark.svg`：使用 `currentColor` 的主矢量。
- `translay-loop-mark-black.svg`：黑色版本。
- `translay-loop-mark-white.svg`：白色版本。
- `optical/`：48、32、20、16px 的独立光学版本。
- `windows/`：Windows PNG 与 ICO 输出。
