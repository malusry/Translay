# 临时译文缓存

2026-09-19：TranslationService 增加仅驻留内存的成功译文缓存，无新依赖、界面入口或磁盘缓存。

- 最多 24 条，缓存原文/请求键和译文字符串合计不超过 1 MiB（不含少量容器开销）。超大条目跳过缓存。
- 每条成功结果从生成完成起保留 10 分钟；命中不延长有效期，容量满时优先淘汰最久未使用项。过期条目在后续读写时移除，退出程序后全部清空。
- 键包含完整 TranslationRequest 和 ModelConfig，包括原文、上下文、来源应用、语言、模式、术语表、格式要求、模型地址、名称及思考设置。原文不额外去空格或模糊匹配。
- API 模式命中前仍读取并校验凭据是否存在；凭据使用进程随机哈希指纹参与隔离，不将明文密钥放入缓存键或日志。
- 只保存最终解析成功的译文和可选语气附注。错误、空译文、连接测试、详细解释均不进入这套缓存。已有纯公式本地直出规则不变。
- 不合并同时进行中的请求；每个请求继续走现有取消和过期响应隔离流程。快速命中使用既有快速结果显示逻辑。

验证：177 项 Rust 库测试通过、1 项忽略。新增测试覆盖命中不调用获取函数、失败后重新获取、语气附注保留、到期失效、LRU、容量限制，以及原文/上下文/模式/模型/凭据隔离。测试使用固定数据，不调用付费模型、不读取真实密钥。

缓存命中意味着复用最近成功结果，不代表模型服务当前在线。同一服务地址背后的模型若被外部替换但配置未变，旧结果最多保留至有效期结束；重启也可清空。
