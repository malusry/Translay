## 职责与加载

`src/shared/uiFonts.css` 统一声明三个本地字体及 `--font-interface`、`--font-display`、`--font-reading`。各界面 CSS 只选择对应角色；全局 `base.css` 的默认字体保持原样。`uiFonts.ts` 在相关视图初始化时预载本地字形，不安装系统字体，不使用 CDN 或在线服务。

菜单在本地字体加载完成后按原有动画帧／64ms 兜底通知原生显示。字体完成回调检查视图销毁和当前 generation；旧会话不能显示或聚焦新会话。加载失败记录警告并释放字体就绪等待，CSS 使用系统字体回退，菜单可以继续操作。未改变 WebView 的创建线程、配置窗口单例或退出保护。

字体子集只包含静态界面字形，输入的其他文字通过显式 Unicode 范围回退到系统字体。界面文字新增后应重新运行裁剪工具；不要读取用户配置或凭据来生成字集。Noto 保留 100–900 变量字重，得意黑和文楷使用原有单字重，不合成粗体。

三个 WOFF2 共 125,956 字节（约 123.0 KiB）。使用 `?no-inline` 强制独立资源，避免小字体变成被现有 CSP 拒绝的 data URL；安全策略和项目依赖不变。来源、固定版本、源文件与产物哈希见 [字体资源说明](../src/shared/fonts/README.md) 和 `manifest.json`。字体文件元数据及资源目录保留版权和 OFL 许可。

`Settings.tsx` 负责真实请求等待、同步重复点击锁、局部请求编号和输入失效；沿用 `draftSignature`，对两个新 API Key 的变化只在内存中比较，不把密钥写入 signature 或报告。地址、模型、超时、凭据、后端、预设或翻译偏好变化使旧请求失效，异步本地模型检测及保存回填也通过输入变化校验。结果回写同时检查请求编号、当前输入、视图存活及活动配置归属，旧请求的 `finally` 不能解除新请求的锁。后端请求不被取消，不增加自动重试或等待计时器。`settingsState.ts` 仅组织反馈文字，`SettingsView.tsx` 提供状态图标、装饰描边和可访问描述，CSS 负责外观与固定布局；IPC、请求协议、超时值、凭据保存及提供商逻辑保持。

隐藏配置窗仍保留 React 视图和草稿：输入未变化的请求可在隐藏期间完成，重开后显示同一结果；关闭或 Escape 清除未保存 API Key 时，涉及该 Key 的旧测试失效。仅切换设置分类或最小化不使未变化的输入失效。实际卸载使请求编号失效，旧实例完成不能写入重挂载后的页面。

验收复用 `tests/browser/brand-regression.cjs` 的模拟 IPC，以可控制的 Promise 完成顺序检查重复点击、输入变化、两种乱序、旧 `finally`、后端／预设／活动模型归属、隐藏保留和实际 StrictMode 卸载重挂载。浏览器还检查长诊断、失败重试、键盘、减少动态效果、680×570／960×720 与 100%／125%／150%／200% 设备比例，并继续执行保存、模式和字体回归。原生工具只在完整 Debug 的真实 WebView2 中投射 CSS／文字状态并恢复 DOM，证明原生尺寸、描边、图标和反馈几何；它不发起模型测试，不能作为原生真实请求或人工托盘、多屏视觉验收。复现、测试、截图及构建详情见 [本轮报告](../tests/artifacts/settings-connection-report-20261009.md)。

## 配置页模式选择动效（2026-10-09）

翻译页采用已确认的「柔和淡彩铺开」：从模式标记的外圈中心展开真实圆形色层，边缘柔化，并由原卡片的 12px 圆角裁切，最终覆盖整个模式卡片。色层用 300ms 同时展开和渐深，最终透明度为 0.65；内圆点用 180ms 原地缩放和渐显，沿用 14px 外圈及 6px 圆点。2026-10-09 后续确认改为同心圆点：外圈和圆点放在同一 SVG 的共同圆心，不再上移 0.5px，缩放以 SVG 视框中心为原点。日常／学习的颜色及三个字体角色、卡片网格与内外边距、文案、配置窗口尺寸保持原样。

圆圈与模式名称组成居中对齐的标题行，两种字体使用同一个 20px 行高，两个卡片的标题行保持同高。说明文字另起一行，与名称左侧对齐，标题与说明保留 5px 间距；说明正常换行，不影响圆圈与名称的对齐。不增加设置、按钮或额外组件层级管理。

`SettingsView.tsx` 内的局部 `ModeChoice` 复用两种模式的标题行、同心标记与色层，只在布局初始化或卡片尺寸变化时测量外圈中心和最远角，使用实际边框宽度避免分数 DPI 的整数取整偏差；`ResizeObserver` 随组件卸载释放。`settings.css` 负责标题／说明对齐、圆形扩散、圆角裁切和固定中心缩放，替代原先的卡片／圆点弹跳和悬停位移。文字与卡片本身在切换时不移动，不增加动画循环、计时器、依赖、用户设置或按钮。

选中状态继续由 `Settings.tsx` 的现有配置驱动：点击立即更新，保存期间屏蔽重复操作，失败后恢复上一选择并允许重试；不改变 IPC、模型字段、凭据或保存逻辑。进入翻译页不会重播已选项动画，再点同一选项也不会重播；连续切换直接从当前过渡状态反向，不重置色层。系统要求减少动态效果时取消这条链路的过渡。
