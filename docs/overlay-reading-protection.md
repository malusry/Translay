# 浮层到期交互保护

2026-09-11

- 保留原有按译文长度计算的阅读时长；到期前移入、移出不会提前关闭或重置计时。
- 到期时鼠标仍在浮层内，或仍按住鼠标进行选择，则推迟自动关闭。
- 到期后的交互结束且鼠标离开后，等待 500 ms，再执行现有淡出动画。后台轮询可能额外带来约 50 ms 的检测延迟。
- 等待期间重新移入取消关闭；再次离开重新等待 500 ms。
- 已松开鼠标的文字高亮不永久固定浮层。失焦释放交互保护；恢复鼠标移动时也会清除丢失 mouseup 留下的状态。
- 手动关闭、Escape 和详细解释面板原有的固定显示逻辑保持不变。

## 复制反馈与内部选区隔离

- 划词监听在鼠标按下与松开时检查实际命中的原生根窗口，排除 Translay 自身窗口。适用于不抢占前台焦点的浮层及其 WebView 子窗口；从浮层内拖出也不会启动新的选区探测，内部点击不会成为外部双击的前一次点击。
- 复制请求进行期间暂缓自动关闭，成功或失败后均保留至少 1 秒反馈，然后恢复悬停/离开保护。手动关闭仍可立即触发。
- 新选区清理旧复制计时器；迟到的旧复制成功或失败不会覆盖当前复制状态，也不会释放新选区的保留状态。
- 两项完成后统一构建一次 release。前端 80 项、Rust 157 项通过（1 项需显式输入的评估测试跳过）；浏览器回归增加复制反馈与旧请求成功/失败测试。原生测试创建并销毁不可见根窗口与子窗口，验证所有权过滤，不改变桌面焦点。尚未做完整桌面应用的手动式端到端验收。
