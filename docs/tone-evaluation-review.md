# 日常语气附注验收 · 2026-09-09

本轮完成了此前被 TLS 证书问题阻断的真实模型复验。连接恢复后保持证书校验，使用已配置的 `deepseek-v4-flash`，翻译思考仍关闭，未修改用户配置。仅发送合成句子。

## 方法

[预注册样例与标准](../tests/evaluation/tone-cases.json)包含 18 条开发样例，分普通事实、词汇、惯用表达、委婉表达、模糊短答和明确上下文六组，每组三条；另保留六条新样例。每条独立请求两次。不设随机种子或温度，沿用应用请求设置。

先检查 JSON、字段、附注长度、词典行数和应为空的附注；再由助手逐条审阅译文及附注。不是独立盲法评审，也不是统计显著性实验。允许措辞不同和可选附注缺省，不把“有附注”当成质量指标。部分开发题此前已出现在提示词中；保留题未用于调整本轮提示词。

## 结果与取舍

| 提示词 | 请求数 | 人工通过 | 可润色 | 明确问题 |
|---|---:|---:|---:|---:|
| 原版本 | 36 | 30 | 3 | 3 |
| 追加规则候选，未采用 | 36 | 29 | 2 | 5 |
| 重整结构候选，开发集 | 36 | 35 | 1 | 0 |
| 同一候选，保留集 | 12 | 11 | 0 | 1 个格式问题 |

原版本出现一次把未指定的 offer 译为“不去了”、一次给反语增加“随便说说而已”、一次无依据概括“语气轻松自然”。简单增加规则的候选还出现把完整口语误判为词典等退步，因此未采用。

最终版本把响应格式、词汇/完整话语判断、翻译忠实度和可选附注分开说明，删除了多段拼接产生的指令冲突。保留集的 charge 一次返回六项词义，揭示首版结构化解析绕过了既有五项限制；现已恢复该处理。未将这个样例改进伪装成模型本身通过格式要求。

[最终原始输出与生产解析后的结果](tone-evaluation-final.json)包含 48 次响应：严格 JSON 均可解析；原始词典上限异常一次。经生产解析后，47 次满足本轮基本验收标准，1 次仍可润色：`I was wondering...` 被译为“我刚才在想……”，时间暗示多余。未发现无依据情绪推断。24 次本应无附注的响应均返回 null；全部 48 次中仅 5 次带附注，说明当前策略偏克制，不意味着对所有其他文本都有相同表现。

此次共 120 次合成请求，含被拒绝的候选。最终 48 次请求的耗时中位数约 0.78 秒，仅反映该次网络及模型条件。

## 实现修正

- 日常模式使用单独、完整的 `tone_prompt.txt`，不再依赖替换旧提示词字符串拼出新协议。学术提示词和公式分支未改动。
- 结构化译文再次经过原有词典限制，至多保留五项；长段落保持完整。
- 日常紧凑浮层测得实际文本宽度不足时改用换行布局，由既有高度测量适配，避免窄窗口省略译文。
- 保持 11px 淡色附注、按需出现和只复制译文。

## 可复用检查

真实调用需要显式 `--live`；脚本先检查 TLS，再读取指定 DeepSeek 凭据，不打印凭据或请求头。报告已有时拒绝覆盖。

```powershell
python tests/evaluation/tone_eval.py --live --split main --label next-check

# 本地生产解析器回放，不调用模型；报告中的提示词必须与当前应用一致。
$env:TONE_EVAL_REPORT = (Resolve-Path 'docs/tone-evaluation-final.json').Path
cargo test --manifest-path src-tauri/Cargo.toml replay_saved_tone_evaluation -- --ignored --exact translation_service::tests::replay_saved_tone_evaluation

# 需当前 Node 环境可以解析 playwright；读取生产解析得到的 displayedOutput。
node tests/browser/reading-regression.cjs
```

前端类型检查、73 项前端测试、156 项常规 Rust 测试，以及单独运行的 48 响应生产解析回放测试通过。 生产解析后的 48 条结果在 320px、560px 两种宽度下共 96 次浏览器回放全部通过，包括加载/结果切换、完整译文、无水平溢出、复制隔离、旧附注丢弃及失败重试。既有公式、详细解释取消和缓存回归同时通过；新版可执行文件构建成功。浏览器使用模拟 Tauri IPC 驱动真实 Overlay 组件；它覆盖显示、复制和交互逻辑，不等于 Windows 原生 UIA/剪贴板捕获端到端验收。
