# 开发浮层验收

这个入口复用正式的 Overlay、解释面板、CSS 动画、OverlayManager 及原生定位/高度调整代码；不维护另一套浮层。

## 运行

在项目根目录的普通 Windows 终端中运行：

- 四角自动验收：`npm run acceptance -- --all`
- 右下角公式：`npm run acceptance -- --corner=bottom-right --sample=math`
- 左下角短译文：`npm run acceptance -- --corner=bottom-left --sample=short`
- 手动查看：`npm run acceptance -- --manual --corner=bottom-right --sample=long`

可用位置：bottom-right、bottom-left、top-right、top-left。样例：long、short、math。手动模式保留浮层，不自动消失；使用真实的解释按钮操作，点击浮层关闭按钮退出。运行时不要同时开启第二个验收实例。

脚本先打包自带前端资源的 debug 可执行文件，无需另外启动 Vite。验收进程使用 tests/artifacts/acceptance-webview 独立浏览器缓存；退出后脚本清理它。报告保存在 tests/artifacts/acceptance-位置-样例.json。自动模式有内部 25 秒保护，外部脚本最多等待 35 秒；超时或校验失败返回非零退出码。

Codex 文件系统沙箱中，WebView 启动可能停滞，需要通过正常审批机制在沙箱外运行这条测试命令；不能把这种失败解释为浮层布局失败。

## 自动检查范围

固定样例在当前主显示器工作区内显示。调用真实解释按钮的事件处理流程，执行展开、收起，检查：

- 三个阶段的原生窗口边界是否在屏幕工作区内。
- 可见按钮矩形是否在 WebView 可视区内。
- 展开时是否只进行了避免越界所需的垂直移动，宽度及水平位置是否稳定。
- 收起后是否保持展开时的位置并恢复高度（允许分数缩放带来的 1 个物理像素取整差）。
- 译文滚动位置是否保留。

报告包括物理坐标、尺寸、缩放比例、前端可视区、滚动位置与通过状态。自动点击由开发脚本调用真实 DOM 按钮，并非操作系统鼠标注入。报告不代表鼠标悬停、跨应用选文、在线模型服务或人的视觉美感已验收。可以运行手动模式由用户查看动画及实际鼠标体验。

## 隔离边界

Rust 模块和启动分支均由 cfg(debug_assertions) 包围。release 不注册验收命令、不包含样例及自动脚本。测试进程在正常初始化之前独立运行，不加载模型配置/凭据、不创建托盘、不注册全局快捷键、不启用选区监听；只使用固定的译文/解释。复制操作为测试空操作，不覆盖用户剪贴板。正式应用的自动消失策略不改动；测试进程单独确认交付以保持窗口显示。

唯一共用代码整理是在 windows.rs 将原有浮层构造提取为可传入数据目录的函数，正常运行仍使用原来的目录和窗口属性。测试报告是开发产物，不进入安装包。

## 本次验证（2026-09-18）

Windows 主屏 150% 缩放、工作区 2560×1528：长译文四角、右下角公式、左下角短译文，共 6 个原生场景通过。长译文展开及收起后 scrollTop 保持 100；公式及短译文无须滚动。JSON 报告保存在上述 artifacts 目录。其他缩放比例、多显示器及真实鼠标操作未纳入本次自动验收。

前端 91 项测试通过；Rust 库测试 166 项通过、1 项忽略。WebView 退出时可能输出 Chrome_WidgetWin_0 注销警告；验收以报告、进程退出码及缓存清理结果共同判定，不以单条 Chromium 日志替代检查。

正式 exe 构建通过；检查二进制确认验收报告标识与自动脚本标识在 debug 中存在、在 release 中均不存在。测试缓存已清理，JSON 报告保留。
