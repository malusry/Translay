# 日常模式语气附注首版

日常翻译在同一次模型请求中返回 `translation` 和可选 `toneNote`。附注仅用于解释有文本依据的惯用表达、委婉表达或语域；普通事实、孤立词汇及语境不足的短答默认不生成。现有译文风格保留在 translation 字段；生成式输出的具体措辞不保证与旧提示词逐字相同。

浮层采用已确认的 11px 淡灰绿文字与极浅雾绿渐变背景。有附注时短译文使用上下布局；无附注时保留原有紧凑布局，不留下空行。附注参与内容测量与滚动。复制只读取译文字段。学术翻译、公式重建与详细解释继续使用原路径。

后端接受规范 JSON、完整 JSON 代码围栏及旧式纯文本译文。缺失、空白、重复、超过 48 字或多行附注被忽略；有效译文仍保留。损坏的 JSON 响应显示既有失败/重试入口，不把响应封装显示为译文。附注通过 React 文本节点显示，不解释为 HTML。

## 首版真实模型验收历史

见 [合成样例记录](tone-note-smoke.json)。使用已配置的 DeepSeek 模型，未修改用户配置。首轮 6 条合成样例中，5 条符合严格 JSON 格式；词典查询未满足严格 JSON 解析。语义审阅发现孤立的 Fine 被过度解读、礼貌请求附带了不充分的“不满”推断。

随后移除了词典提示中的 JSON 引号/外部格式冲突，并明确缺少语境时不推断勉强、讽刺或不耐烦。修订后的 8 条复验均在网络连接阶段失败；独立连接检查显示 TLS 证书域名与 api.deepseek.com 不匹配。未绕过证书校验。第二轮结果不能用于评价修订提示词质量，需在连接恢复后重试。这是小样本冒烟检查，不能视为系统性质量评测。
