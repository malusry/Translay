# 精简解释验收

目标：补足直译没有讲清楚的含义、关系或概念，帮助用户继续阅读。核心解释不设标题，通常 1–3 句；关键概念最多两个；必要提示只描述影响当前理解的具体歧义。限定条件写入正文，不重复罗列。通用基础知识可以辅助理解，但不能被当作当前论文的事实。

以下是语义验收样例，不要求模型逐字复现。1、2、12 用于提示词示范，其余保留为独立验收。每例同时检查 JSON 合法、无重复栏目、公式转义正确。

| # | 原文及上下文 | 期望解释与取舍 |
|---|---|---|
| 1 | `The estimate is approximate.` | 这个估计值是近似结果，并非精确值。无需概念或提示，不虚构误差大小。 |
| 2 | `power`；前文：`The test detects a true effect with probability 0.8.` | 此处指统计检验检出真实效应的能力，而非功率或权力。无需再列 power 概念。 |
| 3 | `selection bias`；前文：`Only volunteers were included.` | 自愿参加者可能与总体不同，使结果产生系统性偏差；不能补写偏差方向或大小。 |
| 4 | `X is associated with Y, but causality has not been established.` | X 与 Y 有关联，但尚不能据此认为 X 导致 Y。把限定写入正文，不再添加同义提示。 |
| 5 | `The method converges if the objective is convex.` | 收敛结论以目标函数凸性为条件；不能把充分条件解释成必要条件。可补充凸性的简短基础含义。 |
| 6 | `Not all participants improved.` | 并非所有参与者都改善，至少有人没有改善；不能解释成所有人都没有改善。 |
| 7 | `This reduces the variance.`；前文：`We average independent measurements.` | This 指对独立测量取平均；解释波动减少，不补写样本量或下降比例。 |
| 8 | `This supports the claim.`；无上下文 | 说明某项证据为一个主张提供支持，但不是证明。必要提示指出 This 与 claim 的具体指代无法确定，不编造论证关系。 |
| 9 | `The 95% confidence interval excludes zero.` | 区间未包含零；可解释置信区间的重复抽样含义，但不声称参数有 95% 概率落在本次区间中，不推断估计方法或实际重要性。 |
| 10 | `$y=ax+b$`；上下文：`a is the slope and b is the intercept.` | y 随 x 按线性关系变化；按需解释斜率和截距，不求解或枚举所有变量。 |
| 11 | `We divide the scores by $\sqrt{d_k}$ before softmax.`；上下文：`d_k is the key dimension.` | 解释分数按维度平方根缩放后再输入 softmax 的顺序；公式使用正确 LaTeX，不编造实测效果。 |
| 12 | `√ab`；无上下文，译文假定为 `$\sqrt{ab}$` | 只能确定涉及平方根和 a、b；必要提示指出无法确定 b 是否在根号内，不能把译文的重建假设当成事实。 |

验收方法：用当前配置的模型分别提交原文、可用上下文与译文，保存实际输出；逐例记录是否满足目标、是否遗漏条件、是否无依据补充、是否重复、是否返回有效结构。尤其检查小模型的 JSON / LaTeX 转义。提示词中的三例不能替代其余独立样例。未调用真实模型时，不得将此表标为通过。

## 等待体验与取消（2026-09-06）

- 解释加载超过 8 秒后显示“仍在生成解释，可随时关闭”；关闭、重开和错误重试会清理并重置计时器，不显示百分比或虚构进度。
- 关闭解释时发送 `cancel_explanation(requestId, attemptId)`。重置浮层、组件卸载也会清理未完成请求；后端在新划词或清空当前捕获时同样取消旧解释。
- 每次生成使用独立递增 attemptId，取消早于开始到达时保留取消记录，迟到的旧取消不会影响新请求。后端仅允许当前未取消的尝试写入缓存，前端同时用序号和加载状态拦截迟到结果。
- 后端通过 oneshot 信号结束等待并丢弃正在执行的 HTTP future，覆盖连接、响应读取及兼容重试等待。完成与取消同时就绪时优先取消。这里是客户端取消，不承诺服务商立即停止计算或计费。
- 已完成的解释仍可复用；未完成就关闭的解释，下次打开会重新生成。请求超时仍使用原模型设置，失败后通过原按钮重试，不增加自动模型调用。

验证：149 项 Rust 测试、70 项前端测试、类型检查和生产构建通过。新增回归覆盖先取消后开始、快速重开、迟到取消/完成、新划词/隐藏取消、等待 future 被释放、同时完成与取消、同一捕获的迟到前端结果。浏览器使用真实解释组件及受控时钟验证 8 秒提示、关闭、重开计时重置和错误重试。未使用真实付费模型，未重新执行原生 PDF 全链路验收。临时检查在内存执行，测试浏览器与服务器已关闭。

本节取代上一版“关闭后请求仍可能在客户端后台完成”的行为说明；仍不能保证服务端的取消和计费行为。
