# 等待与译文切换

2026-09-19：本轮只调整前端等待反馈与动画衔接。

- 等待内容在 110ms 后开始显示。若结果在此之前返回，直接显示结果，不补播尚未出现的等待壳退场，也不人为延迟结果。
- 等待已经显示时，继续使用原有的展开动画与阅读计时确认流程。
- 读取中转为翻译中时，重新记录等待窗口的坐标，避免随后从过期位置展开。
- 翻译阶段持续 8 秒后，原位置的提示变成“仍在翻译”。完成、失败、切换请求或卸载时取消计时器，不增加面板或窗口尺寸。

验证：类型检查、92 项单元测试通过。新增浏览器测试 loading-regression.cjs，覆盖快速结果、8 秒提示、提示尺寸、请求切换、计时器清理、交付确认与等待窗口移动后的展开起点。快速场景固定 performance.now，避免机器调度速度影响阈值测试；位置测试使用模拟窗口坐标。

已有 selection-race-regression.cjs 和 reading-regression.cjs 均通过，包含连续选区、过期响应、复制、公式、解释面板、阅读位置及失败重试检查。这些是实际 React 组件配合模拟 IPC 的浏览器检查，不等同于真实模型耗时或原生窗口动画观感验收。
