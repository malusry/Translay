# 浮层定位

2026-09-18：调整首次显示及译文尺寸更新时的位置选择，继续使用选区所属显示器的工作区（排除任务栏）。

- 选区先裁到当前工作区内，避免屏幕外的选区部分影响定位。
- 优先在选区下方展示，允许横向移动到屏幕内；其次上方，再次右侧、左侧。侧向展示允许纵向微调。
- 所有方向均不足时，将候选位置限制到工作区内，选择与选区重叠面积最小的位置。同分按上述顺序选择，保证结果稳定。
- 原生窗口尺寸不超过工作区大小。对于选区占满屏幕的情况，无法同时保证完全避开原文，只能减少遮挡。
- 解释展开、收起仍使用原有保留位置策略，只在越界时作必要移动。
