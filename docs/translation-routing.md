# 学习模式翻译路由修正

本轮只处理数学识别与短术语上下文，不继续调整详细解释质量规则。

## 数学与普通内容

- 明显的完整代码片段、长下划线标识符、文件名、路径、URL 和标量配置项在学习模式中原样返回，避免被模型改写。
- 独立公式通过完整公式分隔符、数学符号、短变量和常见运算符组合识别。覆盖 x_i、d_k、x=1、根式、分式、希腊字母和压平 Attention 公式。
- 含公式的正文使用学术翻译提示加混合数学补充规则：完整翻译正文，只将数学片段恢复成 LaTeX，区分行内与独立公式。无邻近上下文时同样生效；代码和 URL 不触发这条规则。
- 含数学符号的正文不再套用词典结果最多五行的截断逻辑。

这仍是保守启发式规则，不是代码或数学解析器。x=1 无法仅凭文本区分代码赋值与数学等式；罕见函数或复杂未加分隔符的公式可能回退普通翻译。尚未接入视觉识别，也不保证 PDF 结构恢复无误。

## 短术语与上下文

学习模式中，power、attention、selection bias 等词或短语使用已经取得的前后文；输出仍为简短编号释义。提示词要求上下文能消歧时通常只返回一个含义，最多五个，不罗列无关释义。上下文只用来判断含义，不进入译文。无上下文时保留原有词典入口，日常模式不发送邻近文本。

## 本地验证

Rust 140 项测试、前端 65 项测试通过；新增了软件字面量、独立公式、混合正文、上下文双侧传递和无上下文回退测试。格式、编译和 TypeScript/前端构建通过。本轮未追加外部模型调用，因此验证的是路由及请求内容，实际译文质量仍取决于模型。

混合选区修复：补充公式加段落、句末标点、公式内部空格、无上下文和代码排除的回归；前端验证同一段中的独立公式、行内公式及正文可以共存。本轮验证路由、提示词和渲染，不等于保证模型对任意 PDF 恢复正确。

## 混合公式检查补充

参考 [Attention Is All You Need 第 3.2.1 节、公式 (1)](https://arxiv.org/html/1706.03762v7#S3.SS2.SSS1)，核验独立公式、行内缩放因子、公式加中文段落三类渲染样例。正文为测试用改写，不是模型实测译文。

- 修复后端按单个反引号奇偶排除代码的问题：双反引号代码中的 x_i 会误触发混合数学路由。现在按完整反引号串匹配结束位置，并覆盖内嵌反引号、四反引号和未闭合代码的回归。
- 替换旧混合渲染测试中不清晰的转义写法；检查 MathML 中的分数、根号、上下标及外部 V，同时验证原文段落、公式编号和引用没有丢失。
- Rust 143 项、前端 69 项测试通过，TypeScript 与生产前端构建通过。浏览器使用真实浮层 CSS，在 320/560 px 宽度下检查公式与正文共存，未发现外层横向溢出，独立公式保留内部横向滚动。
- 本轮未调用真实模型、未执行原生 PDF 划选；不代表对模型恢复能力或 PDF 捕获链路的完整验收。
- 检查脚本通过标准输入在内存执行，未新增临时脚本、截图或模型输出文件；浏览器与预览服务已关闭。保留修复、回归用例及本记录。

## 自动翻译方向 · 2026-09-21

默认目标由固定 `zh-CN` 改为 `auto`。日常、学习、短术语、混合公式和独立公式路由均在系统消息中携带同一份方向策略：简体/繁体中文以英文为目标，其他自然语言以简体中文为目标。独立公式继续恢复结构，受保护的软件字面量仍保持原样。

方向在原本的一次模型请求内根据选中文本的主要自然语言判断，不新增检测调用、开关或浏览器扩展。中外文混排按句法与语义判断，代码、路径、URL、数字与数学符号不参与方向判断；本地脚本统计仅作提示。邻近上下文只帮助消歧，不能覆盖明确的选中文本语言。真正无法消歧的混排平局以中文为目标。这是模型指令，不能保证任意模型对所有模糊短词判断正确。

移除了日常、学习和混合数学提示中的固定中文译文要求，保留模式风格、公式规则与中文语气附注。仅中文输出采用既有中文字符数排版提示。缓存键已包含 targetLanguage，自动规则不会与内部固定方向请求混用；缓存本身仅在进程内存在。加载提示改为“正在生成译文…”。

验证：Rust 181 项通过、1 项忽略；前端 92 项通过，TypeScript 检查通过。新增回归覆盖双模式请求中的简繁中文、中英技术混排、网址/代码、混合公式、日文和法文，并确认源文本/上下文传递及英文结果、中文附注解析。它们验证请求构造和输出处理，不是在线模型翻译质量评测；本轮未调用外部模型。
