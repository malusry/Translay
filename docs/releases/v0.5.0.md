# Translay v0.5.0

Windows x64 正式版，包含自 v0.4.0 以来完成的界面和交互更新。

- 改进翻译浮层阅读、段落与数学公式显示，支持详细解释、失败重试和连续选区请求隔离。
- 日常模式支持简短语气附注；成功译文在有容量和时限的内存缓存中复用，退出后清空。
- 更新折叠丝带图标与托盘菜单。单击切换划词图标，快速双击切换日常／学习模式，并显示轻量反馈。
- 每次重新启动默认开启划词图标；本次运行仍可关闭，重开配置窗口不会重置开关。
- 统一配置与托盘字体，优化保存和连接测试按钮、稳定反馈布局及完整失败原因查看。
- 修复连接测试重复请求、编辑中旧结果、乱序回写及后端／提供商健康状态归属。
- 改进配置窗口隐藏、重开、恢复和旧会话操作隔离。

安装方式：下载 `Translay_0.5.0_x64-setup.exe`，按当前用户安装。已有模型配置和 Windows 凭据沿用原存储；安装前从托盘退出正在运行的 Translay。

开发检查包含前端与 Rust 单元测试、模拟 IPC 浏览器回归和隔离原生 WebView2 验收。程序化窗口操作不等于 Windows 隐藏托盘面板、物理鼠标手势和多屏视觉验收；这些人工项目仍需按开发文档确认。本次发布过程不调用真实模型、不读取日常配置或用户凭据。
